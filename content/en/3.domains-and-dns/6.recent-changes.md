# Recent changes

**Recent changes** shows what changed in the organization's zones, by whom and with what outcome.

You find the page under **Domains** → **DNS** → **Recent changes**. The same page is available in **Cloudflare DNS**. The **Changes** button on a zone page opens the page filtered to that zone. You need the **View DNS zones and records** permission.

## The list

Each row is a change, with the columns **Time**, **Change**, **Zone**, **By** and **Outcome**. The latest change comes first. The list shows 50 rows at a time. Click **Show more** to see more.

**Change** is one of:

- **Record created**, **Record changed** or **Record deleted**
- **Zone created**, **Zone deleted** or **Zone imported**
- **Redirect changed**
- **Portal administration** — changes to how the zone is shown in the portal, for example that it is hidden, shown or activated

A change can also be tagged with the feature that made it, for example **Email security** or **SSO**. Several records changed at once, for example with **Select records**, are shown as one row, "… changes in one run", which you can expand.

A zone that has been deleted or hidden is marked **(deleted)** or **(hidden)**.

### By

- a person's name, with the provider's name in parentheses when someone at your provider made the change
- **API key**, when the change was made with an API key
- **System**, for automatic changes
- **Unknown user**, when the person cannot be shown
- another organization's name with **(via shared access)**, when a recipient of a shared zone made the change. See [Shared access](/en/domains-and-dns/shared-access).

Email addresses are only shown to those with **The organization's log** permission.

### Outcome

| Outcome | Means |
|---|---|
| **Done** | The change went through. |
| **Rejected** | The change was refused, and nothing changed. |
| **Restored** | The change failed, and the original record was put back. |
| **Restore failed** | The change failed, and the original record could not be put back. |
| **Unknown outcome** | It could not be determined whether the change was made. |

## Details of a change

Click a row to see the details. Under **Before and after** every field that changed is shown, with the value before and after.

For a change with **Unknown outcome**, the DNS server's answer never arrived. Click **Check the current record** to compare the record as it looks now with what the change was meant to do. The result is **Wanted state observed**, **Different state** or **Could not be checked**.

The check shows the record's current value, not who set it. The outcome on the row is never changed afterwards.

## Filter

Filters are shown as chips above the list and are kept in the address bar, so you can save or share the link.

- **Period** — **Last 24 hours**, **Last 7 days** (default), **Last 30 days** or **Custom range** (at most 366 days).
- **Zone** — including deleted and hidden zones.
- **Kind of change** — **Records**, **Zones**, **Redirects and parking** or **Portal administration**.
- **By**.
- **Outcome** — changes with an unknown outcome. **Unknown outcome** shows those no check has confirmed yet. **Followed up** shows those that have been checked.
- **Record name** — records whose name contains the text, for example `www`.

## How far back the history goes

At the top of the page it says from which date history is available, for example "History is available from …". Changes belong to the organization where they were made. If the organization takes over a zone, the zone's earlier history is not shown.
