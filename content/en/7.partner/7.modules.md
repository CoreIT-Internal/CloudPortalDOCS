# Modules

Under the tenant's **Modules**, a provider or distributor controls which modules the organizations under it get. The page shows "Applies to your {count} organizations. Changes are saved only after you have seen what they do."

The page is in the menu for those who can administer the tenant.

How a single organization sees and changes its modules is described in [Modules](/en/organization/modules). There the rule is: "The nearest choice applies: your own, else the provider’s, the distributor’s and last the platform’s. A lock at any level comes before all of them."

## The columns

Each module has its own row.

| Column | What it does |
|---|---|
| **Lock for everyone under you** | "Takes the module away from every organization, whatever they chose." Choose **No lock**, **Hidden**, **Locked**, **Coming soon…** or **Own message…**. With the last two you write a **Text shown**. |
| **Default for organizations** | "Applies to organizations that have not chosen." Choose **Follow the level above**, **Active**, **Not activated** or **Hidden**. **Follow the level above** takes the distributor's or the platform's choice. |
| **Organizations now** | How many organizations have the module active, not activated and hidden, for example "12 active · 3 not activated · 0 hidden". Click to see the organizations. |
| **Exceptions** | How many single organizations (for a distributor: providers) you have locked the module for. Click to see and change them. |

If the module is locked by a level above you, that is shown instead of the choices, and the row says "Has no effect under the lock".

With **Show** you filter the list: **All modules**, **With a lock**, **With an own default** or **With exceptions**. You can also search for a module.

## Save changes

1. Change the lock or default for one or more modules. The row is marked **Changed**, and at the bottom it says how many changes are not saved.
2. Select **Preview**. The dialog shows what the changes do to the organizations, for example how many become inactive and how many chose themselves and keep their choice.
3. Select **Save {count} changes**. "Applies from the next page load, for everyone."

**Undo** discards changes that are not saved. If something changed while you were looking, the preview shows new numbers, and nothing has been saved.

::warning
A lock comes before the organizations' own choices. Check the preview before you save a lock.
::

## Exceptions

An exception is "Your lock on a single organization, with a reason it sees." For a distributor, the exceptions apply to providers.

1. Click the number under **Exceptions**.
2. Select **Add an exception**.
3. Choose the organization under **For**.
4. Choose how the module is shown under **Shown as**: **Hidden**, **Locked**, **Coming soon…** or **Own message…**.
5. Write a **Reason (shown to the one restricted)**.
6. Select **Save the exception**.

**Remove the exception** gives the organization its usual state back.

## The organizations for a module

Click the numbers under **Organizations now** to open the **{module} · organizations** list. You can filter by state and search for an organization. Each row shows the organization's state and why it applies.

As a provider you can change a single organization directly in the list:

- **Reset to default** — removes the organization's own choice, so that it follows the default again.
- **Switch off…** — switches the module off for that organization with an exception. Choose **Shown as**, write a reason and select **Switch off for the organization**.
- **Remove the exception** — removes an exception.

A distributor sees the list but cannot change it. The organization's provider does that.
