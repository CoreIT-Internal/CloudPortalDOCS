# MCP key

An MCP key is an [API key](/en/organization/api-tokens) that reaches only MCP. Use it for tools and integrations that cannot sign in with OAuth.

::tip
If your tool can sign in with OAuth, like Claude, Claude Code and Visual Studio Code, you are better off connecting [your own AI client](/en/ai-clients/connect-ai-client). The log then shows which person called, and the connection follows your permissions.
::

::note
To create an MCP key you need the **Organization administration** permission. The key reaches only the organization it is created in.
::

## Create an MCP key

1. Open **Settings** → **API keys** and click **New MCP connection**.
2. Give it a name and choose under **What the assistant may do**. You can only give what you hold yourself.
3. Choose under **Which zones**: all of the organization's zones, including future ones, or selected zones only. Choose how long the key lasts and click **Create connection**.
4. Copy the key. It is shown only once.

## Use the key

The tool connects to the MCP address with the key as a Bearer token in the `Authorization` header.

::warning
An MCP key reaches only MCP, and an ordinary API key never reaches MCP.
::

## Revoke

Revoke the key in the **API keys** list, just like other [API keys](/en/organization/api-tokens). It stops working immediately.
