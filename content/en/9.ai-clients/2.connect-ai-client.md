# Connect your AI client

All you need is the portal's address. The AI client finds the sign-in itself, and you approve the connection in CloudPortal.

The **Connect an AI client** guide is also in the portal under **My account** → **AI connections**, with the address, the steps for your client and the **Wait for the connection** button, which shows when you have approved and when the client has made its first call.

## The address

```text
https://portal.coreit.cloud/api/mcp
```

## 1. Add CloudPortal in your AI client

::tabs

:::tabs-item{label="Claude (web and Desktop)"}

1. Open Claude and go to **Settings** → **Connectors**.
2. Add a custom connector, name it **CloudPortal** and paste the address.
3. Choose **Connect**. The browser opens CloudPortal.

With Claude Team or Enterprise an owner adds the connector under **Admin settings** → **Connectors**. Everyone then connects under **Settings** → **Connectors**.

:::

:::tabs-item{label="Claude Code"}

1. Add the server in a terminal:

   ```bash
   claude mcp add --transport http cloudportal https://portal.coreit.cloud/api/mcp
   ```

2. Start Claude Code, run `/mcp` and choose **cloudportal** to sign in. The browser opens CloudPortal.
3. The command `claude mcp list` then shows the server as connected.

:::

:::tabs-item{label="Visual Studio Code"}

1. Open the Command Palette and run **MCP: Add Server**.
2. Choose **HTTP**, paste the address and name the server **CloudPortal**.
3. When VS Code asks: sign in. The browser opens CloudPortal.

:::

:::tabs-item{label="Other clients"}

An AI client that can connect to MCP servers with OAuth uses the address above and finds the sign-in itself.

CoreIT has so far tried Claude, Claude Code and Visual Studio Code. If the connection does not work with another client, [contact support](/en/support/contact-support).

:::

::

## 2. Approve the connection in CloudPortal

The browser opens the **Connect AI client** page.

1. **Sign in** as usual, if you are not already signed in.
2. **Check the client.** The page shows the client's name and where the response is sent. If it says **The name is reported by the client itself**, the client has given the name itself. Only approve if you recognize the connection and started it yourself.
3. **Choose customers.** You see the customers you reach, grouped by how you reach them: **As a member**, or as the partner you work for. A customer that has turned off AI clients cannot be chosen, and the page says who can change that. You can choose at most 50 customers per connection.
4. **Choose permissions** for each customer. What you may read is preselected, while permissions marked **Propose changes** are yours to choose. You can only give permissions you hold yourself.
5. Click **Approve**. The browser is sent back to the AI client.

::note
You must have signed in within the last 10 minutes to approve. Otherwise the page shows **Confirm your sign-in**: enter your password (and the code if you use two-step verification), or sign in again with your sign-in service if you use SSO. Read more under [Troubleshooting](/en/ai-clients/troubleshooting).
::

## 3. Make the first call

Ask the client something, for example "Which customers can you reach in CloudPortal?". Under **My account** → **AI connections** it then says **Verified: first call** with the time. If you are waiting in the guide, you see it there too: first that the client is approved, then **Done** when the first call has arrived.
