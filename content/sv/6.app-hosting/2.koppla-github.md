# Koppla GitHub

När ett GitHub-konto är kopplat väljer du repot ur en lista när du importerar en app. Kopplingen görs med **CoreIT CloudPortal GitHub App**, som du installerar på de repon du väljer.

::note
Appen ser bara de repon du själv ger den åtkomst till på GitHub.
::

## Vem kan koppla GitHub

Du behöver behörigheten **Hantera leverantörer och källkopplingar**. Det är en känslig behörighet som Ägare och Administratör har som standard. Samma behörighet krävs för att koppla bort ett konto.

Saknar du behörigheten kan du ändå importera ett publikt repo, eller välja en koppling som en administratör redan har gjort. Se [Importera app](/sv/app-hosting/importera-app).

## Hitta sidan Anslut GitHub

Sidan **Anslut GitHub** har ingen egen menypost. Du når den från importguiden:

- **Anslut GitHub →** visas när inget GitHub-konto är kopplat ännu.
- **Hantera GitHub-anslutningen →** visas under repolistan när ett konto redan är kopplat.

## Första kopplingen gör CoreIT

Du installerar appen på GitHub själv, men en ny installation knyts till er organisation av CoreIT. Så här går det till:

1. Välj **Installera GitHub App** på sidan **Anslut GitHub**. "Du skickas till GitHub för att välja vilka repos appen får åtkomst till. Därefter kommer du tillbaka hit automatiskt."
2. Logga in på GitHub om du inte redan är inloggad.
3. Välj konto eller organisation, och om appen ska se alla repon eller bara de du väljer.
4. Bekräfta installationen. Du kommer tillbaka till portalen, där det står "Slutför anslutningen …" en kort stund.
5. För en ny installation visas sedan: "GitHub-installationen är inte kopplad till den här organisationen ännu. Kontakta CoreIT så knyter vi ihop den."
6. Kontakta [support](/sv/support/kontakta-support). Berätta vilket GitHub-konto eller vilken organisation du installerade appen på.

När CoreIT har knutit ihop installationen syns kontot i importguiden, och du kan välja repot ur listan.

::note
Installationer som redan är kopplade till er organisation fungerar som vanligt. Det gäller också ett nytt konto du lägger till med **Anslut fler GitHub-konton**: det kopplas ihop av CoreIT på samma sätt.
::

## När installationen är kopplad

Kommer du tillbaka från GitHub till en installation som redan är kopplad visas **GitHub anslutet** med:

- **Konto** — GitHub-kontot eller organisationen.
- **Typ** — om det är ett användarkonto eller en organisation.
- **Status** — till exempel **Installerad**.
- **Anslutna repos** — hur många repon appen har åtkomst till, och en lista över dem.

Härifrån kan du:

- välja **Fortsätt — importera app →** för att gå direkt till importguiden,
- välja **Tillbaka till översikten**,
- öppna **Hantera installationen på GitHub ↗** för att ändra vilka repon appen ser,
- välja **＋ Välj fler repos i GitHub ↗** eller **＋ Anslut fler GitHub-konton ↗**.

## Anslutna GitHub-konton

På sidan **Anslut GitHub** listas under **Anslutna GitHub-konton** de konton där appen redan är installerad för er organisation. Varje rad visar kontots namn och en statusetikett:

- **Installerad** — kopplingen fungerar.
- **Behörigheter saknas** — appen är installerad men behöver fler behörigheter (se nedan).
- **Pausad** — installationen är pausad på GitHub.
- **Repo borttaget** / **Avinstallerad** — kopplingen behöver återställas.

Vill du ge appen åtkomst till fler repon, välj **Hantera installationen på GitHub ↗** på kontots rad. Välj sedan **⟳ Uppdatera** i importguiden så att de nya repona visas.

## Behörigheter saknas

För att bygga appen från GitHub behöver GitHub-appen normalt kunna:

- skriva innehåll i repot (för att lägga in en workflow-fil),
- skriva filer under `.github/workflows`,
- läsa och skriva repots Actions-hemligheter.

Saknas något visas en varning på appens sida: "GitHub-anslutningen saknar behörighet för att skriva workflow och Actions-secrets. Installera om GitHub-appen med rätt behörigheter och försök igen." Varningen listar vad som saknas. Länken **Hantera GitHub-koppling** öppnar GitHub, där du ger appen rätt behörigheter.

::warning
Saknas behörigheter kan bygget inte slutföras. Åtgärda behörigheterna på GitHub innan du går vidare.
::

## Koppla bort ett konto

1. Välj **Koppla bort** på kontots rad.
2. Portalen frågar: "Avinstallera appen från detta GitHub-konto? Den tas bort på GitHub."
3. Välj **Ja, koppla bort**, eller **Avbryt**.

::warning
Ett konto som används av en eller flera appar kan inte kopplas bort. Portalen svarar då till exempel "Kan inte kopplas bort — används av 2 app(ar). Ta bort apparna först." Ta först bort apparna som använder kontot, koppla sedan bort det.
::
